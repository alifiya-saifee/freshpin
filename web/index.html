How it works

  1. An AI model (via Bifrost) splits the answer into time-sensitive claims.
  2. Tavily searches the live web for the current value of each claim.
  3. A second model, via Bifrost, judges each claim using only those sources.
  4. A fixed formula turns the evidence into a 0 to 100 freshness score.
  5. Stale facts get a new version, and every decision pinned to the old one is reopened for a person to re-approve.
